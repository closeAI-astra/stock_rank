データの出どころ

  • 株価・株探/IRBANK の企業データ(決算・配当・財務・有報など)・信用残・貿易統計: stockAI(Future Sight) が公開している暗号化データを、このページがブラウザ内で復号して表示します。Future Sight と同じパスワードで開きます。
  • 保存データ: このリポジトリの GitHub Actions が取得したものです。株探(kabutan-weekly.yml、毎週水曜の朝)が定期取得の本線で、IRBANK(irbank-archive.yml)は使えなくなる前の一度きりの保存です。信用残は、stockAI に無い日付だけを株探保存 → IRBANK保存の順でつなぎます。
  • チャート描画: TradingView の Lightweight Charts™(Apache-2.0)。

チャートの操作

  • ドラッグ=横移動、ホイール/ピンチ=拡大縮小、価格軸のドラッグ=縦の伸縮、ダブルクリック=リセット。
  • 左の ― で水平線、╱ で2点のトレンドライン。描画は銘柄ごとにこの端末に保存されます。
  • 「サブチャート」で RSI・MACD・ストキャスティクスに加え、信用買残/売残・信用倍率・推定評価損益率・残高金額を下段に出せます。
  • 右のウォッチリストの「指数」で、日経平均・TOPIX・NASDAQ・S&P500・VIX・米10年債・ドル円のチャートに切り替えられます(検索欄に「日経」などでも可)。日本株の指数では、サブチャートの信用残・信用倍率に市場の信用残を出します。株探・IRBANK から東証全体の値を保存できていればそれを、無ければ stockAI の対象銘柄(約400)の合計を使います。下段には指数の統計・投資部門別売買・騰落と業種を出します。
  • 表示テーマ(Light / Dark / Prototype / Earth)やチャートの既定は「設定」で変えられます。テーマは Future Sight と共有で、同じ github.io では選んだテーマが両方に効きます。「/」キーで検索欄へ。
  • 「決」の印は決算発表日です(インジケーターで切り替え)。発表日の値動きは下段の「決算発表」タブで一覧できます。

信用残の金額と推定評価損益率

信用評価損益率は「信用で買った(売った)建玉が、いまの株価でどれだけ含み損益を抱えているか」を表す値で、市場全体の値しか公表されていません。そこで、個別銘柄の申込日ごとの残高から次のように推定します。

  1. 金額: 買残金額 = 買残(株) × 申込日の終値、売残金額も同様。
  2. 取得コスト: 前回の申込日から残高が増えた分は、その期間の VWAP(典型価格を出来高で加重)で新しく建ったとみなして積み上げます。
  3. 減った分: 既定は先入れ先出し(古い建玉から返済)。制度信用の期日 6 か月(182日)を過ぎた建玉は、期日の終値で乗り換えたとみなして単価を置き直します。もう一つの方法(移動平均法)は、減った割合だけコストを比例で減らします。
  4. 評価損益率: 買い方 = 買残金額 ÷ 取得コスト − 1、売り方 = 1 − 売残金額 ÷ 取得コスト。

JPX などの公表ミスが分かっている日(現在は 2026-10-20 の日次信用残)は、表には ⚠ を付けて残し、前回比・金額・評価損益率・合計の計算から外します。

最初の観測日は「その日の終値で建てた」と置くので、履歴の最初の約半年は 0% 寄りに出ます(表では薄く表示)。株式分割は、分割日の前後の残高の跳びから信用残が未調整かを自動判定して、金額が連続するように揃えます。一般信用・貸借の区別、現引き・現渡しは残高からは分からないため、あくまで目安です。

全銘柄合計の推定損益率は、各銘柄の金額とコストを足し合わせてから割ったもの(金額加重)です。

株探・IRBANK の保存

株探(これから): 自分の PC のタスク スケジューラ(scripts\register_weekly_task.ps1 で登録)が毎週水曜の朝に動き、Future Sight の対象銘柄の信用残(週次)・決算(業績・配当)・銘柄トップを取って、信用残の履歴を積み増します。初回は手動で mode=full にすると、信用残の過去ページや大株主などのページもまとめて取ります。

IRBANK(今回だけ): 自分の PC で scripts\run_local.ps1 を一度実行すると、信用残・空売り・貸借などの個別ページをすべて保存します。途中で止まっても毎日続きを取り、全銘柄そろった後は IRBANK に接続しません。

株探・IRBANK とも GitHub のサーバーからの接続を拒否するため、取得は自分の PC で行います(手順は README「自分の PC で実行」)。

表示している数値は情報提供のためのもので、投資助言ではありません。
